# Fictional Booster

A small mobile-friendly landing game: tap to fire a short upward thruster and land the booster softly on the pad.

**Play:** https://fatum22.github.io/Fictional-Booster/

This repo hosts the Godot 4 web export (Compatibility renderer, single-threaded) served by GitHub Pages. The game's source lives in [Fatum22/docklight](https://github.com/Fatum22/docklight).
